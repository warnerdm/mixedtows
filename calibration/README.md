# Calibration (copies)

`ecs_checklist.csv` holds the Lake Huron rows of bloaterTS `calibration/ecs_checklist.csv` that have an ECS file,
and the ECS files are copies of bloaterTS's (commit c27739e, 2026-10-14). bloaterTS is the master: when a Huron
calibration changes or is added there (Sturgeon 2012, 2013, 2017, 2018 are missing), copy the row and file again.
